# 港通 OA / 考勤 用户脚本

内部使用的 [脚本猫（ScriptCat）](https://docs.scriptcat.org/) 用户脚本，用来加快 OA 工作记录录入、让考勤日历的打卡记录一眼看全。

仅供公司同事内部使用，匹配的站点均为内网地址。

## 脚本列表

| 文件 | 作用 |
| --- | --- |
| [scripts/oa-gangtongkeji-work-record-time.user.js](scripts/oa-gangtongkeji-work-record-time.user.js) | OA 工作记录弹层：一键填上午 / 下午时间，可自定义预设，自动选默认工作类别与工作类型 |
| [scripts/hrm-attendance-calendar-scroll.user.js](scripts/hrm-attendance-calendar-scroll.user.js) | 考勤日历：每个日期格子的打卡记录自动滚到底，完整显示 4 条 |

## 安装

1. 给浏览器装脚本猫扩展（Edge 商店）：
   <https://microsoftedge.microsoft.com/addons/detail/%E8%84%9A%E6%9C%AC%E7%8C%AB/liilgpjgabokdklappibcjfablkpcekh>
   （Chrome 用户可在 Chrome 商店或脚本猫官网安装，脚本本身通用）
2. 点下面链接，脚本猫会自动弹出安装页，点「安装」即可：
   - 工作记录时间快捷填充：<https://raw.githubusercontent.com/DeYinyv/gangtong-oa-userscripts/main/scripts/oa-gangtongkeji-work-record-time.user.js>
   - 考勤日历自动滚到底：<https://raw.githubusercontent.com/DeYinyv/gangtong-oa-userscripts/main/scripts/hrm-attendance-calendar-scroll.user.js>
   - 也可以把 `.user.js` 文件下载后拖进脚本猫管理面板，或新建脚本粘贴内容
3. 安装完成后确认脚本处于「启用」状态，然后刷新对应业务页面。

## 1. 工作记录时间快捷填充

适用页面：OA → 工作记录 → 「新增工作记录」弹层。

弹层标题栏右侧会多出三个小按钮：

- **上午**：点一下把时间范围填成 `08:00 - 12:00`
- **下午**：点一下填成 `13:00 - 17:00`
- **设置**：打开预设时间设置面板

设置面板说明：

- 上午、下午两组各有开始 / 结束时间，都是 15 分钟粒度的下拉，格式 `HH:mm`
- 保留原有「工作类别 = 系统开发」「工作类型 = 案头工作」的默认选择，打开弹层时自动选中，手动改过不会被反复覆盖
- 校验：时间必须符合 `HH:mm` 且为 15 分钟粒度，结束时间必须晚于开始时间，否则面板内红字提示，不会保存
- 保存后立即生效，并且持久保存：刷新页面、关掉弹层再开、重启浏览器都还是你设的值
- 「恢复默认」一键回到 `08:00 - 12:00` / `13:00 - 17:00`
- 点面板外面任意位置即可关闭；按钮不会影响弹层标题拖动和关闭

注意：按钮只在点击时写入时间，不会自动改动你已经手动填好的内容。

## 2. 考勤日历自动滚到底

适用页面：HRM 考勤 → 考勤日历。

- 每个日期格子里的打卡记录会自动滚动到最底部，4 条打卡完整可见
- 切换月份后新出现的日期格子同样生效，打卡数据异步加载完也会再滚一次
- 只做显示层面的滚动，不修改、不提交任何考勤数据

## 常见问题

**安装后按钮没出现？**
确认脚本已启用；确认打开的是「添加工作记录」弹层（标题文字必须一致）；刷新页面后重开弹层。脚本只在匹配的弹层标题上注入按钮。

**改了预设时间但没生效？**
已打开的弹层不会自动刷新，重开一次弹层即可。若同时装了同名脚本的旧版本，先删掉旧版本。

**设置面板里的时间选不到想要的？**
控件是 15 分钟粒度，只能选 `00`、`15`、`30`、`45` 这样的分钟。

**换电脑后设置没了？**
预设时间保存在脚本猫的本地存储里，不随账号同步，换电脑 / 换浏览器需要重新设置一次。

**考勤格子还是没滚到底？**
等页面打卡数据加载完，脚本会在内容变化时自动再滚；仍不行就刷新页面重试。

**脚本会把数据发到网上吗？**
不会。两个脚本只操作页面 DOM 与浏览器本地存储，没有任何网络上传。
